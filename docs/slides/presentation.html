FloodLens Kenya · Esther Wairimu Kamau · 1 Problem and user

Officers get more flood reports than they can check

  • Reports arrive as photo + text, in English, Kiswahili and Sheng
  • Some are real, some are old photos, some try to trigger alerts
  • Duty officers in Nairobi, Kisumu and Tana River decide what to escalate

Design principle

A missed alarm costs more than a false one. So nothing is ever dropped, and nothing is ever sent without a person approving it.

7 · Security and compliance

Reports are data, never instructions

  • API keys with roles; only officers see the queue or approve
  • Kenyan phone + email redaction before storage
  • No raw report text or PII in logs (tested)
  • Injection guard: no auto-draft if suspected
  • Photos with a person → privacy marker (Kenya DPA 2019)
  • MCP queue tool returns scores only
  • secret_refs.yaml names secrets, never values
  • Live mode with no keys refuses every request
