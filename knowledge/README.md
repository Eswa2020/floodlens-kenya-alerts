# Guidance document set (RAG corpus)

Eight short teaching summaries that FloodLens retrieves from when it drafts guidance.
They were written for this project from general, widely published flood-safety practice.
**They are not official guidance** and do not quote any agency. Every answer FloodLens
drafts points residents to the official channels in `config.json`.

| id | file | topic |
|----|------|-------|
| G01 | g01_moving_water.md | Moving water and roads |
| G02 | g02_evacuation.md | When and how to evacuate |
| G03 | g03_riverside.md | Riverside and low-lying settlements |
| G04 | g04_electricity.md | Electricity and gas during floods |
| G05 | g05_after_flood.md | Water and health after a flood |
| G06 | g06_official_channels.md | Where official warnings come from |
| G07 | g07_officer_protocol.md | Duty officer approval protocol |
| G08 | g08_reporting.md | How residents should report flooding |
